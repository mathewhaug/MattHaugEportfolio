Tech Experiment: Algorithm Efficiency

As part of a bonus assignment, I wanted to push my students beyond standard coursework by having them design the most efficient algorithm possible. Their solutions would be tested against a massive set of input data automatically to see which approach scaled best under pressure.

My original plan was to let students submit their code, which would then run directly on my personal server. This setup would allow objective, automated benchmarking of performance across many test conditions.

However, I ran into two significant roadblocks. First, I couldn’t allow student code to execute on a personal server it falls under institutional data governance policies, and my system is technically the property of St. Clair College. Second, after exploring deployment through college servers, I was advised by IT that allowing dozens of simultaneous code executions would resemble a denial-of-service event which could compromise system performance for the entire campus network.

While the challenge couldn’t move forward as planned, the experiment opened the door to future solutions: containerized execution environments, sandboxed code runners, and possibly collaborating with cloud platforms. I still plan to revisit this idea because when students compete for efficiency, they engage with complex code solutions that they may have never thought of before
